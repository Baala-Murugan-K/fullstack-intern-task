4. Core & Bonus Feature Specifications

A. Authentication & Security

  • User Registration & Login: Input validation for name, email format, and password length (minimum 6 characters).
  • Password Hashing: Passwords hashed using bcryptjs before storage.
  • JWT Session Management: Stateless tokens stored in localStorage with auto-refresh and logout capability.
  • Supabase Email Verification (Bonus): Integrated email verification workflow. Unverified logins trigger confirmation prompts with resend functionality.

B. Template Store Catalogue

  • Pre-Seeded Database: 8 production-grade SaaS templates across categories: CRM, Analytics, AI Tools, Developer Tools, E-Commerce, Project Management, Fintech, Customer Support.
  • Live Keyword Search (Bonus): Real-time filtering matching template title, description, or category.
  • Category Filter Pills (Bonus): Dynamic category filter buttons with reset options.
  • Template Card & Details: High-resolution previews, category badges, and interactive detail modals.

C. Favorites Management

  • Interactive Toggle: 1-click favorite and unfavorite buttons with elastic heart pop animation.
  • Protected Favorites Section (Bonus): Dedicated /favorites page accessible only to authenticated users, redirecting guests to login with redirect-back support.
  • User-Specific Collection: Relational join queries ensure each user sees only their saved items.

5. Database Schema & Architecture

Table Fields Relationships & Constraints
users id (PK, Serial), name (String), email (String, Unique), password (String), created_at (Timestamp) Primary user credentials store.
templates id (PK, Serial), name (String), description (Text), thumbnail_url (String), category (String), created_at (Timestamp) Catalog of available SaaS templates.
favorites id (PK, Serial), user_id (FK), template_id (FK), created_at (Timestamp) Foreign keys referencing users(id) and templates(id) with ON DELETE CASCADE and unique pair constraint.

6. RESTful API Endpoint Reference

Method Endpoint Description Authentication
POST /api/auth/register Registers a new user and issues a JWT token. Public
POST /api/auth/login Authenticates user credentials and returns JWT token. Public
GET /api/auth/me Returns profile data for the authenticated user. Bearer Token
GET /api/templates Lists all templates. Supports ?search= and ?category=. Public
GET /api/templates/:id Returns details for a specific template. Public
GET /api/favorites Lists all templates favorited by the logged-in user. Bearer Token
POST /api/favorites/:id Adds a template to the logged-in user's favorites. Bearer Token
DELETE /api/favorites/:id Removes a template from the user's favorites. Bearer Token

7. Local Setup Instructions

To run the application locally for review:

  • Clone: git clone https://github.com/Baala-Murugan-K/fullstack-intern-task.git && cd fullstack-intern-task
  • Backend: cd server && npm install && npm run dev (Runs at http://localhost:5000). Auto-seeds local SQLite if DATABASE_URL is omitted.
  • Frontend: In a second terminal: cd client && npm install && npm run dev (Runs at http://localhost:5173).
  • Run Tests: In server/, execute npm test to run the 14-step integration test suite.
